# Security Policy

## Supported versions

Security fixes are applied to the current default branch. The local demo is not approved for regulated or production data.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue containing exploit details, credentials, workbook content, authorization data, private work notes, or personal information.

Include the affected component, reproduction steps using fictional data, impact, and any suggested mitigation. Maintainers will acknowledge a complete report, assess severity, and coordinate a fix and disclosure timeline.

## Demo warning

The local demo accounts and password are public and intentional. They are blocked by production settings but must never be deployed as real identities. Production use requires separate identity, infrastructure, privacy, retention, backup, incident-response, and compliance reviews.
